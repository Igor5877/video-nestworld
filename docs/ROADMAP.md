# World Utilities (nestworldvideo) — плани та нотатки

Записано зі сесій розробки. Нічого з розділу «Заплановано» ще не реалізовано, якщо не позначено інше.

## Вже зроблено (станом на цю гілку)

- Відео на екранах з кількох блоків: власний декодер FFmpeg (однаково на всіх ОС), VLC як альтернатива, режим `auto`.
- Спільна часова лінія екрана (ігровий годинник), автокорекція розсинхрону, автоперехід/повтор, «Продовжити», історія перегляду (локально в кожного гравця).
- Просторовий звук, сумісність із шейдерами (BSL/Oculus), режими збільшення (бікубічний, «слідує за лініями», Anime4K-lite — тест).
- Налаштування в грі: сторінка в Embeddium, кнопка у ванільних налаштуваннях відео, Mods → Config, шестерня в меню кінотеатру.
- Релей HLS на сервері (кеш сегментів, автоперемикання за кількістю глядачів, запасний вихід на прямий доступ).
- 18+: рейтинг Hikka, право `nestworldvideo.adult`, заглушка на екрані для гравців без доступу, команда `/nestworldvideo adult everyone|ops|nobody|status`.
- Діагностика: `debug_stats = true` пише в лог швидкість годинника, черги, розсинхрон, рендер.

## Заплановано

### 1. Кілька джерел відео (стійкість)
- Єдиний інтерфейс провайдера джерела: пошук, список серій, посилання на потік.
- Один тайтл — кілька джерел; об'єднувати за ідентифікатором Hikka/MAL.
- Автоперемикання на інше джерело тієї ж серії, якщо потік не відкрився чи обірвався; перевірка «здоров'я» джерел.

### 1a. Фільми (спробували і прибрали, лишили лише аніме)
Що було зроблено й зараз відкочено (коміти для повернення коду: `4f9369c` інтерфейс джерел + ручний список `/films reload`, `899fc4a` вкладка «Фільми», `445dd4e` пошук TMDB `/films search|add`; відкат у наступному коміті):
- Каталог фільмів із TMDB (офіційний API, ключ безкоштовний; українські назви, постер `image.tmdb.org/t/p/w342`, 18+ за `adult` або сертифікацією NC-17/18/X у UA/US/GB/DE).
- Ручний список `config/nestworld-films.json` з кількома джерелами на фільм (перше робоче виграє) і вкладка «Фільми» у меню екрана.

Чому не лишили: аніме працює автоматично, бо Hikka знаходить тайтл, а AniUA API віддає серії з посиланнями Ashdi. Для фільмів такої ланки «назва → потік» немає:
- Ashdi (`ashdi.vip/vod/<id>`): ID власні, не TMDB/IMDb; пошуку й API (`/api/search`, `/api/vod/…`) не знайдено (404).
- AniUA API: пошуку фільмів немає.
- Eneyida: сторінка фільму відкривається, але плеєр підтягується скриптом, готового посилання в HTML немає. Парсинг сайту (як у розширеннях CloudStream `CakesTwix/cloudstream-extensions-uk`, ліцензія GPL-3.0, тож лише як довідник, код не брати) крихкий: ламається при зміні верстки.
- Усі ці сайти без ліцензії на розповсюдження контенту (ризик такий самий, як з Ashdi).
Якщо повертатися: спершу перевірити на живих відповідях, як Eneyida віддає плеєр; вставляти посилання вручну можна було вже зараз.

### 2. Режим події
- Запуск у вказаний час із відліком, синхронний старт; керування лише в організаторів.
- Попереднє завантаження серії в кеш релею перед початком.

### 3. Караоке-івент
- Етап A: бібліотека пісень із «паспортами» (автор, статус прав, термін), випадковий вибір, текст (LRC) лише для співака, мінус на екрані.
- Етап B: голос з ефектами (ехо/реверб) через API Simple Voice Chat: подію `MicrophonePacketEvent` можна скасувати, `OpusDecoder/OpusEncoder` та позиційні/статичні канали доступні в API. Співак у навушниках (мінус потрапляє в мікрофон).
- Етап C: оцінка за висотою голосу (ноти формату UltraStar) і нагорода.
- Пульт ведучого: баланс мінус/голос, ехо/реверб, авто-приглушення, кнопки (оплески, фанфари), черга, таблиця результатів. Пізніше: MIDI-контролери («режим навчання» через `javax.sound.midi`).
- Права та джерела: див. розділ «Правові нотатки».

### 4. Якість на величезних екранах
- Сервер з RTX: окремий процес-«робітник» (зовнішній ffmpeg з libplacebo + NVENC) збільшує потік один раз для всіх, релей роздає результат. Anime4K як шейдер — у реальному часі; AI-моделі (Real-ESRGAN) — лише попередня обробка. Орієнтир: 1440p (4K — для сильних клієнтів). Приклад команди (не перевірено): `ffmpeg -i потік.m3u8 -vf "hwupload,libplacebo=w=2560:h=1440:custom_shader_path=Anime4K_Upscale_CNN_x2_M.glsl" -c:v hevc_nvenc -b:v 12M -c:a copy out.m3u8`.
- Клієнтська нейромережа (справжній Anime4K CNN, ваги MIT): окремий прохід у проміжну текстуру раз на кадр відео (вартість не залежить від розміру екрана); не працюватиме з шейдерами; опція з попередженням про навантаження.
- Підготовка до 4K-джерел: YUV-завантаження кадра, апаратне декодування, буфер за часом, а не за кількістю.

### 5. Адміністрування
- Хто керує екраном: власник / список / усі.
- Адмін-меню каталогу: додати/прибрати тайтли, позначити 18+, заборонити реліз, журнал запусків.
- Свої файли з диска сервера як безпечне джерело (через релей).
- Субтитри й вибір аудіодоріжки.

## Правові нотатки (не юридична консультація)

- Публічне виконання музики потребує дозволу правовласника або ліцензії організації колективного управління (ОКУ); виняток для «фонової» музики закон не передбачає, джерело звуку значення не має.
  Джерела: [НІПО: Guide for business](https://nipo.gov.ua/wp-content/uploads/2025/06/Guide-for-business_ANTI-PIRACY-MUSIC-1.pdf), [музика в ресторані](https://ipacademy.nipo.gov.ua/wp-content/uploads/2026/07/muzyka_v_restorani_yak_vykorystovuvaty_pravomirno.pdf), [The Page](https://thepage.ua/ua/experts/muziku-zamovlyali-hto-povinen-platiti-za-vikoristannya-pisen-v-gromadskih-miscyah), [Mind.ua про закон №5572](https://mind.ua/news/20236098-prezident-pidpisav-zakon-pro-royalti-na-avtorski-prava).
- Власний мінус (запис) знімає лише права на фонограму, права автора на твір лишаються.
- Безпечніші джерела: народні пісні, твори з закінченим терміном захисту, письмовий дозвіл автора/лейбла, ліцензія ОКУ.
- Фільтр пісень — лише список дозволених (немає автоматичного розпізнавання «вільного»): паспорт у кожної пісні, невідомі/прострочені не потрапляють у випадковий вибір.
- Не транслювати/записувати івент зі звуком без дозволу (платформи можуть блокувати). Не накопичувати збережені копії відео.
- Тексти пісень: [LRCLIB](https://github.com/tranxuanthang/lrclib) — безкоштовний API синхронізованих текстів, але ліцензію даних не перевірено, текст пісні сам по собі захищений.
- Музика з відкритою ліцензією: [Jamendo](https://support-artist.jamendo.com/jamendo-licensing) — ліцензія різна для кожного треку; публічний показ слід узгодити.

## Безпека й 18+

- Заглушка на екрані — чесний фільтр, не захист від зламаного клієнта (відео клієнт завантажує сам).
- Для публічного сервера: `default_access = "ops"` (за замовчуванням) і права через LuckPerms. Донат не підтверджує вік; брати плату за доступ до відео зі сторонніх хостингів ризиковано.

## Сумісність із NestworldCore (регіональні потоки)

Сервер-частина мода виконується в основному на головному потоці (мережеві пакети, таймер релею, права); блок екрана не має власного такту. Дрібні межі: зміна блока з головного потоку при збереженні чанка в регіоні; `saveAdditional` оновлює позицію. Рекомендація: тест «кілька глядачів + релей + автоперехід» з `/nestworld entityguard`.
