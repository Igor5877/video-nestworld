# Команди, права, клавіші та налаштування

Усе нижче описано за кодом мода (`nestworldvideo`). Команди вводяться в чаті гри або в консолі сервера.

## Команди

| Команда | Права | Що робить |
|---|---|---|
| `/aniua <назва або slug>` | оператор (рівень 2) | Знаходить аніме в Hikka за назвою (або за готовим slug), завантажує серії з AniUA і зберігає їх у каталог сервера (`config/videos.json`). Якщо збігів кілька, мод просить вибрати аніме в меню екрана. Новий каталог одразу надсилається всім гравцям. |
| `/reloadvideo` | оператор (рівень 2) | Перечитує `config/videos.json` з диска, очищає кеші Hikka та AniUA і надсилає оновлений каталог усім гравцям. Корисно після ручного редагування файлу. |
| `/nestworldvideo adult everyone` | рівень 3 | 18+ доступне всім гравцям. |
| `/nestworldvideo adult ops` | рівень 3 | 18+ доступне лише операторам (значення за замовчуванням). |
| `/nestworldvideo adult nobody` | рівень 3 | 18+ недоступне нікому (крім тих, кому явно дозволено право `nestworldvideo.adult`). |
| `/nestworldvideo adult status` | рівень 3 | Показує, що встановлено зараз. |

Примітки:
- `/nestworldvideo adult` без останнього слова нічого не робить (команда неповна).
- Зміна `adult …` записується в `nestworldvideo-content.toml` і діє одразу, без перезапуску. Гравці отримують зміну приблизно за 5 секунд.
- Явне право `nestworldvideo.adult` у плагіні прав (наприклад, LuckPerms) сильніше за значення `everyone/ops/nobody`.

## Права

| Право | За замовчуванням | Призначення |
|---|---|---|
| `nestworldvideo.adult` | за `default_access` (див. нижче) | Дозволяє запускати й дивитися відео з позначкою 18+. Без права гравець бачить на екрані заглушку «18+» і не чує звуку. |

Оператори (рівень 2 і вище) керують будь-яким екраном навіть під захистом сеансу.

## Керування в меню екрана (без команд)

Меню відкривається клацанням по екрану, клавішею `V` (дивлячись на екран) або пультом. Вкладки: «Пошук AniUA», «Бібліотека», «Екран».
- **Захист сеансу** (вкладка «Екран»): кнопка «Захист сеансу: увімкнено/вимкнено» і кнопка «Звільнити сеанс». Хто запустив відео, той керує ним; інші (крім операторів) не можуть його зупинити чи перемкнути. Захист знімається, коли відео зупинене, власник його вимкнув або звільнив, або через 2 хвилини після виходу власника з гри.
- **Збірка екрана** (вкладка «Екран»): «Об'єднати» і «Роз'єднати» плитки в один екран, до 100 × 100 блоків.
- **Налаштування мода**: кнопка ⚙ у меню (також у меню гри → відео, а при Embeddium є окрема сторінка).

## Клавіші (Керування → Nestworld Video)

| Клавіша | Дія |
|---|---|
| `V` | Відкрити меню екрана, на який дивишся (приціл має бути на екрані, сервер перевіряє відстань) |
| `N` | Скасувати автоперехід на наступну серію (поки показується підказка «Далі») |

Клавіші можна змінити в стандартних налаштуваннях керування.

## Файли на сервері

| Файл | Призначення |
|---|---|
| `config/videos.json` | Каталог (усі збережені аніме та серії). Заповнюється `/aniua`, його надсилають усім гравцям. Тільки росте: видаляти непотрібне поки можна лише вручну, потім `/reloadvideo`. |
| `config/nestworld-video-sources.json` | Ручні відповідності `провайдер:id серії` → пряме посилання `https://….m3u8/.mp4`, для серій без готового потоку. Ключі виду `ashdi:62553`, розмір файлу до 256 КБ. |
| `config/nestworldvideo-content.toml` | 18+: `default_access` (`ops`/`everyone`/`nobody`), `adult_ratings` (оцінки Hikka, що вважаються 18+, за замовчуванням `rx`; додай `r_plus`, щоб включити й сильніший еротичний вміст). |
| `config/nestworldvideo-content.toml`, секція `[screen]` | `light_when_playing` (за замовчуванням `true`): екран, що грає, світить (рівень світла 7), великий екран освітлює рівномірну сітку блоків (до ~150 джерел), а не всі. Діє для екранів, що почали або зупинили відтворення після зміни |
| `config/nestworldvideo-common.toml` | Ретрансляція (relay), див. нижче. |

## Ретрансляція (relay), секція `[relay]` у `nestworldvideo-common.toml`

Сервер може кешувати відео й роздавати його гравцям, щоб велика кількість глядачів одного екрана не навантажувала відеохостинг.

| Параметр | За замовчуванням | Значення |
|---|---|---|
| `enabled` | `false` | Увімкнути ретрансляцію |
| `bind_address` | `0.0.0.0` | Адреса, на якій слухає |
| `port` | `25580` | TCP-порт (відкрий у фаєрволі) |
| `public_host` | порожньо | Адреса для гравців; порожньо = та, якою вони зайшли на сервер |
| `min_viewers` | `3` | Від скількох глядачів екран переходить на ретрансляцію |
| `direct_after_seconds` | `60` | Через скільки секунд після спаду глядачів повертаємось до прямого потоку |
| `cache_mb` | `512` | Пам'ять під кеш сегментів |
| `prefetch_segments` | `4` | Скільки сегментів завантажувати наперед |

Якщо ретрансляція недоступна або повільна (понад 25 секунд на старт), клієнт сам повертається до прямого потоку на 5 хвилин.

## Налаштування клієнта (`nestworldvideo-client.toml`)

Усе це також змінюється в меню (⚙) без редагування файлу.

| Параметр | За замовчуванням | Значення |
|---|---|---|
| `decoder` | `auto` | `auto`, `ffmpeg` або `watermedia` (VLC). Без WaterMedia завжди FFmpeg |
| `max_video_height` | `0` | Максимальна висота відео (0 = найкраща) |
| `max_stream_distance` | `128` | На якій відстані екран працює (блоків), на ній же вмикається авто-VSync |
| `max_active_streams` | `8` | Скільки відео декодується одночасно |
| `render_mode` | `auto` | `auto`, `vanilla_pipeline`, `direct` (з шейдерами автоматично конвеєр гри) |
| `smooth_scaling` | `true` | Бікубічне згладжування |
| `upscaler` | `edge` | `edge`, `bicubic`, `anime4k` (тест) |
| `sharpness` | `0` | Різкість, 0–100 |
| `mipmaps` | `true` | Мипмапи для далеких екранів |
| `spatial_audio` | `true` | Просторовий звук |
| `spatial_softness` | `60` | М'якість просторового звуку, 0–100 |
| `screen_glow` | `2` | Колірне світло екрана на підлозі й стінах за кольорами кадру (темний кадр світить слабко): 0 вимкнено, 1 низьке (радіус 4 блоки), 2 середнє (7), 3 високе (11). Малюється **лише з шейдерами** (Oculus/Iris) |
| `screen_glow_strength` | `60` | Яскравість цього світла, 0–100 % |
| `shader_screen_mode` | `lit` | Як малюється картинка під шейдерами: `lit` (стандарт) або `unlit` (експериментально: не залежить від часу доби, але вицвітає від bloom BSL) |
| `acoustics` | `true` | Акустика приміщення: стіни приглушують звук екрана, у залах луна (потрібні FFmpeg і просторовий звук) |
| `acoustics_reverb` | `60` | Сила луни, 0–100 |
| `acoustics_muffle` | `100` | Сила приглушення стінами, 0–200 %: більше значення робить різницю між матеріалами виразнішою |
| `acoustics_quality` | `2` | Якість променів: 1 швидка, 2 збалансована, 3 детальна |
| `auto_vsync` | `true` | Тимчасово вмикати VSync, коли дивишся відео |
| `debug_stats` | `false` | Писати статистику відтворення в журнал |
| `shaderpack_red/green/blue` | `100` | Корекція кольору екрана під шейдерпаками, 50–100 |

## Обмеження, про які варто пам'ятати
- Каталог надсилається гравцям стиснутим, до ~16 МБ; `slug` аніме до 300 символів; до 2000 серій на одне аніме.
- Захист 18+ працює на боці клієнта, його може обійти модифікований клієнт.
- Версії мода на сервері та в гравців мають збігатися (змінюється версія протоколу).
